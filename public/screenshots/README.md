# Screenshots für NipponGo PWA

Dieses Verzeichnis enthält die Screenshots für das PWA-Manifest.

## Benötigte Screenshots:

1. **screenshot-map-wide.png** (1280×720 px, Desktop/Wide)
   - Zeigt die Kartenansicht im Desktop-Format
   
2. **screenshot-map-narrow.png** (750×1334 px, Mobil/Narrow)
   - Zeigt die Kartenansicht auf einem mobilen Gerät
   
3. **screenshot-planning-narrow.png** (750×1334 px, Mobil/Narrow)
   - Zeigt den Reiseplanung-Tab mit Hotels und Aktivitäten
   
4. **screenshot-timeline-narrow.png** (750×1334 px, Mobil/Narrow)
   - Zeigt die Timeline-Ansicht der Reise

## Hinweise:
- Screenshots sollten die App im tatsächlichen Gebrauch zeigen
- Auf iOS Safari: Screenshots über Safari DevTools oder physisches Gerät
- Empfohlen: Authentifiziert mit Beispiel-Daten (Hotels, Aktivitäten)
- Format: PNG mit guter Qualität
